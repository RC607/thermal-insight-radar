# 隔热情报雷达 · ThermalInsight Radar

面向**透明陶瓷隔热（铯钨青铜 CsₓWO₃）**与**辐射制冷（PDRC）**两个赛道的行业情报检索站点。
两大板块各设 4 个子分类，覆盖 4 个维度：**生产商、产品资料、标准与专利、学术文献**。

零依赖：只用 Node.js 内置模块 + 原生前端，不需要 `npm install`，不需要数据库，不加载任何 CDN 资源。

---

## 一、启动（本地开发 / 需要写入功能时）

```bat
:: 双击 start.cmd，或命令行：
node server\server.mjs --port 8788
```

浏览器打开 <http://127.0.0.1:8788>。端口被占用时自动顺延（8789、8790…），控制台打印实际地址。
要求 Node.js 18+（开发验证于 v24.21.0）。

静态版是**只读**的：写入、在线抓取、X-Mol 导入入口会自动隐藏。

## 三、为什么只有四个维度

你提出"价格、销量、销售额、样板工程这些很难查到，直接去掉"——采纳，并落实到数据模型：

- `data/catalog.json` 里维度只剩 4 个，`project / price / sale` 三个类型从种子脚本中整体移除；
- 服务端 `POST /api/records` 的白名单同步收紧，写入这三类会直接 400；
- 自检脚本 `tools/verify.mjs` 增加一条断言：**库里不得残留已下线维度**；
- 原先把价格案例当作"如何不造假"的示范（如页面自相矛盾的 72000 元/㎡、无单位的"1 万元以下"），现在改为在「来源与口径」页用一句话说明为什么不设这些维度。

代码里保留的诚信规则不变：**无来源 URL 不入库**、**不估算不插值**、**核验等级可见**、**缺口公开列出**。

## 四、页面与功能

- **总览看板**：5 个 KPI、两大板块卡、4 维数据覆盖矩阵（虚线圈缺口）、核验等级堆叠条、文献年度柱状图、企业国别分布、高被引期刊分布、最近入库、缺口清单
- **板块页**：子分类 tab × 维度 tab 双层筛选（均带计数）、子分类内检索、排序、表格/卡片切换、CSV 导出
- **学术文献库**：Crossref 真实元数据（带 DOI）、按板块/子分类/年份筛选、按被引或年份排序、关键词**在线补录**
- **来源与口径**：来源登记表（聚合每条记录的全部出处，按被引用次数排序）、诚信规则、未覆盖缺口
- **情报录入**：表单入库，**无来源 URL 直接拒绝写入**；参数按 `键: 值` 行录入
- **详情抽屉**：完整字段、技术参数表、来源逐条可点、同类型相关记录
- **全站检索**：跨板块跨维度统一检索，结果按维度分组

界面为白底 + 点阵网格 + 双色（琥珀＝透明陶瓷隔热，青＝辐射制冷）的科技风仪表盘，深浅两套色板集中在 `web/app.css` 顶部的 CSS 变量里。

## 六、文献接入：Crossref 与 X-Mol

### 1. Crossref（自动，可用）

服务端调用 `https://api.crossref.org/works`（开放接口，无需 Key），返回结果**每条都带真实 DOI**。

- 界面：文献库 →「Crossref 在线检索」
- 接口：`POST /api/literature/crossref { q, board, subs, rows, persist }`
- 批量种子：`node tools/fetch-crossref.mjs --rows 22`

### 2. X-Mol（合规接入，非静默抓取）

实测 X-Mol 对服务端与 headless 浏览器访问返回「访问受限」，因此**不爬取**，改提供三条路径：

1. **深链检索**：论文行「X-Mol ↗」，在你自己的登录态下打开同名检索页；
2. **粘贴导入**：把 X-Mol 上的条目、DOI 列表、BibTeX 或 RIS 粘贴进来，服务端解析入库并标注来源；
3. **DOI 回链**：Crossref 补录的每条文献都附 X-Mol 检索链接，便于交叉核对。

若持有机构订阅或授权 API，只需在 `server/adapters/xmol.mjs` 增加一个适配函数，其余模块无需改动。

## 九、已知局限（务必先读）

1. **国际覆盖不均衡**：美国（SkyCool）、以色列（SolCold）、日本（SPACECOOL、Radi-Cool Japan）、荷兰（阿克苏诺贝尔，媒体口径）已取到页面；**韩国、欧洲其他地区、东南亚、印度一条成功页面都没取到**，留空而不是猜。
2. **专利维度薄弱**：Google Patents / Justia / FreePatentsOnline / CNIPA 在本环境全部不可读，只收录了有授权报道可核的 4 件（江西银杉超材 3 件 + 寰太 1 件）；美/日/韩/WO 零覆盖。要补全需 CNIPA 账号或 Espacenet OPS key。
3. **部分填料厂商侧证据薄弱**：BaSO₄、Al₂O₃、CaCO₃ 与"铯钨青铜用于辐射制冷"这几条，**没有取到可引用的厂商产品页**（沪正 500、中稀易涂连不通、3M 与 Arkema 403），目前靠学术文献侧支撑。
4. **上游钨源/铯源未入库**：钨酸铵、碳酸铯等只在 ChemicalBook 有供应条目，该站强制人机验证。
5. **配方普遍不公开**：窗膜与涂料品牌只讲技术名（XIR™、纳米陶瓷）与效果，无一家公开成分，相关条目一律标注"未公开配方"。
6. **标准只到元数据**：编号、名称、发布/实施日期、起草单位取自官方标准平台，但技术要求条款（反射比/发射率限值、试验方法）未取证。
7. **两个真实缺口**：铯钨青铜粉体与透明隔热浆料两个子分类在「标准与专利」下没有任何条目——不是漏采，而是目前确实没有针对 CsₓWO₃ 粉体/浆料的产品标准。这项缺口在页面与自检里都是公开可见的。
8. 单机无鉴权，仅监听 127.0.0.1；无定时抓取。
